### Aperçu du projet

La plateforme de tests A/B exécute des analyses d'expériences sur plusieurs variantes web/app, identifie les meilleures versions à partir du comportement utilisateur et des résultats algorithmiques, puis ajuste dynamiquement l'allocation de trafic.

### Architecture

Spring Cloud, MyBatis, MySQL, RabbitMQ, XXL-JOB

### Mon travail

- Implémenté les API de démarrage d'expérience et déclenché des tâches planifiées XXL-JOB selon les horaires définis par l'utilisateur, puis callback vers les API d'exécution.
- Pris en charge la pause/mise à jour/redémarrage des tâches après modification des paramètres, en gardant l'état des tâches et la configuration synchronisés.
- Développé les API de collecte de résultats, fourni les entrées du bandit multi-bras et ajusté l'allocation de trafic des nouvelles versions selon la sortie algorithmique.
- Intégré les API web-vers-PDF et email pour générer et envoyer les rapports d'expérience aux clients.
