## Healthcare Appointment Platform - Intelligent Triage Agent Integration

- **Period:** 2026.06 - 2026.07
- **Role:** Backend / Agent Application Developer
- **Architecture:** Spring Cloud, Spring Boot, OpenFeign, Redis, MySQL, MongoDB, JWT, DeepSeek API, Workflow State Machine

### What I Did

- Designed an independent Agent integration plan to decouple triage dialogue/tool orchestration from core booking services.
- Built workflow states and slots for symptom intake, department recommendation, schedule lookup, booking confirmation, and visit guidance.
- Integrated DeepSeek for intent/slot extraction with backend confirmation guards to prevent unauthorized direct ordering.
- Implemented tool wrappers and observability for hospital, department, schedule, patient, and order operations.
