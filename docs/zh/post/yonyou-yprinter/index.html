用友网络科技股份有限公司 - 安装器开发部

2026.07 - 至今
后端开发工程师

项目名称

YonBIP/iuap 专属化安装器（YPRInstaller）

项目简介

面向 YonBIP 私有化与专属云交付场景的后端安装编排平台，基于 Go 构建，将产品包、中间件、微服务、Nginx、数据库初始化与配置中心发布抽象为可配置、可编排、可追踪的自动化安装流程，适配裸金属、容器云及多资源池部署环境。

技术栈

Go、Beego、DDD/CommandBus、YAML DSL、LevelDB、K8s client-go、SSH/SFTP、MySQL、国产数据库适配

我的工作

  • 参与负责安装任务建模与 DSL 生成链路，梳理产品包、中间件、主机、资源池、云原生参数到可执行安装计划的转换过程，支撑安装、升级、迁移、补丁等多类交付场景。
  • 参与产品安装主流程与插件执行闭环，跟通填参建模、安装计划生成、Actuator 分阶段执行、依赖编排、product / app 插件部署等核心链路，理解 CommandBus 分层下命令分发、领域编排与插件扩展机制。
  • 参与 YMS 配置发布与安装状态回写链路，梳理配置 Build / Check / Publish 流程，以及本地 LevelDB 过程态与远程 CMDB 状态同步机制，协助定位安装状态不一致、配置未发布等问题。
  • 参与裸金属与容器云部署通道适配，在统一阶段模型下区分主机初始化、K8s 资源、Nginx、数据库初始化等执行路径，梳理多环境参数差异、执行分支与插件扩展点。
