我是北京交通大学计算机科学与技术专业硕士研究生，求职方向为 Agent 应用开发与 Java 后端开发。我关注医疗信息系统、智能体工作流、工具调用、RAG 与分布式后端工程，重视把大模型能力稳定接入真实业务流程。

专业技能

  • 计算机基础: 操作系统、计算机网络、数据结构与算法。
  • Java 后端: Java 基础、集合、并发、JVM 基础、Spring Boot、Spring Cloud、MyBatis-Plus、Maven。
  • Agent 应用: Context/Harness Engineering、RAG、MCP、Tool Calling、LangGraph 工作流编排、ReAct 与 Plan-and-Execute 架构。
  • 中间件与工程: Git、MySQL、Redis、MongoDB、Elasticsearch、Kafka、RabbitMQ、Nginx、Docker、Neo4j、MinIO、XXL-JOB。
  • 线上运维与分布式: Linux、日志分析、CI/CD、服务监控、链路追踪、幂等设计、分布式事务、数据一致性、限流、熔断与重试机制。

当前方向

  • 将 Agent 微服务接入既有业务系统，构建可控、可观测、可回滚的工具调用闭环。
  • 围绕医疗预约、导诊和预诊报告生成等场景，打磨 Human-in-the-loop 与状态机驱动的业务工作流。
  • 持续推进新闻驱动股票预测方向研究，论文 Causal Grouping Network for News-driven Stock Forecasting 以一作身份投稿 KDD 在审。
